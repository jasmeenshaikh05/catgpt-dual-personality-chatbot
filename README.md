# 🐱 CatGPT - Dual Personality Generative AI Chatbot

CatGPT is a Generative AI-powered chatbot built using Streamlit and Groq.

The application features two distinct AI personalities:

* 😸 Gamer Cat
* 🐱‍💻 Hacker Cat

Each personality maintains its own independent memory and conversation history, creating a unique interactive experience for users.

---

## Features

### 😸 Gamer Cat

* Friendly and energetic personality
* Gaming-themed humor and responses
* Independent memory and chat history

### 🐱‍💻 Hacker Cat

* Programming and cybersecurity-themed personality
* Technical humor and coding references
* Independent memory and chat history

### Additional Features

* Dynamic avatar switching
* Groq LLM integration
* Context-aware conversations
* Streamlit web interface
* Chat history management
* Clear Chat functionality
